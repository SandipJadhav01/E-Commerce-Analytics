# Uber Power BI Data Analysis Dashboard

## Project Overview
This project analyzes Uber trip data using Microsoft Power BI to identify useful business insights and trends.

## Tools & Technologies
- Power BI
- Excel
- DAX
- Data Cleaning
- Data Visualization

## Dataset
The project uses Uber trip data stored in an Excel file.

## Key Analysis
- Total trips
- Revenue analysis
- Trip trends
- Vehicle/payment analysis
- Location-based analysis
- Business insights
